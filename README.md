# Сайтове за салони — примери

Демо-сайтове за салони за красота с онлайн записване. Всеки е един HTML файл без зависимости.

- `index.html` — страница с всички примери
- `kadife.html`, `noar.html`, `mura.html`, `neon.html` — четири концепции (измислени салони)

Записванията в демотата се пазят само в браузъра на посетителя.
